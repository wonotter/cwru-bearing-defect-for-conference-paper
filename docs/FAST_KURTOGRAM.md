# Antoni Fast Kurtogram 구현

## 구현 기준

Antoni(2007)의 **필터 뱅크 기반 Fast Kurtogram**을 구현한다.
저자가 직접 공개한 `Fast_Kurtogram.m`의 12-2014 개정본을 기준으로 삼았다.
공개 패키지는 2015년 배포되었으며, 저자는 2007년 논문에서 사용한 기본 코드라고 설명한다.

- 논문: [Fast computation of the kurtogram for the detection of transient faults](https://doi.org/10.1016/j.ymssp.2005.12.002)
- 원본 코드: [Antoni의 MATLAB File Exchange](https://www.mathworks.com/matlabcentral/fileexchange/48912-fast-kurtogram)
- 원본 사용 조건: [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md)

## 계산 흐름

1. 원신호의 평균을 제거한다.
2. 복소 FIR 필터 `h`, `g`로 이진 분할하고, 샘플을 2개마다 하나씩 남긴다.
3. 각 이진 가지에 같은 계산을 반복해 다음 이진 레벨을 만든다.
4. 이진 가지에 `h1`, `h2`, `h3`를 적용하고, 샘플을 3개마다 하나씩 남겨 삼진 행을 만든다.
5. 필터 시작 부분의 과도응답을 제외하고 대역별 SK를 계산한다.
6. 음의 SK를 0으로 바꾼다. 최소 폭 600 Hz를 만족하는 칸 중 최댓값을 선택한다.

삼진 가지를 다시 삼진 분할하는 `3^n` 구조는 아니다.
**이진 트리 사이에 삼진 행을 끼워 넣는 구조**이므로 칸 수는 2, 3, 4, 6, 8, 12…로 늘어난다.
Python에서는 행별 반복문으로 트리를 계산한다. 동일한 부모 가지를 재사용하며,
원본의 재귀 함수 `K_wpQ_local`과 같은 대역별 결과를 만든다.

## 레벨과 대역폭

현재 샘플링 주파수는 12000 Hz이고, 양의 주파수 구간은 0–6000 Hz이다.
`KURTOGRAM_NLEVEL = 5`일 때 행 구성은 다음과 같다.

| 표시 레벨 | 칸 수 | 칸 하나의 폭 | 최소 폭 600 Hz에서 선택 |
|---|---:|---:|---|
| 0 | 1 | 6000 Hz | 가능 |
| 1 | 2 | 3000 Hz | 가능 |
| 1.6 | 3 | 2000 Hz | 가능 |
| 2 | 4 | 1500 Hz | 가능 |
| 2.6 | 6 | 1000 Hz | 가능 |
| 3 | 8 | 750 Hz | 가능 |
| 3.6 | 12 | 500 Hz | 제외 |
| 4 | 16 | 375 Hz | 제외 |
| 4.6 | 24 | 250 Hz | 제외 |
| 5 | 32 | 187.5 Hz | 제외 |

삼진 행의 실제 레벨은 `1 + log2(3) - 1 = 1.5849625…`,
`2.5849625…` 등이다. 계산에는 실제 값을 사용하고 그래프에는 1.6, 2.6…으로 표시한다.

**600 Hz는 선택 가능한 칸의 최소 폭이다.** 칸을 600 Hz 간격으로 나누는 설정은 아니다.
선택에서 제외되는 좁은 행도 SK와 색상은 모두 계산해 보여 준다.
따라서 가장 노란 칸과 검은 테두리로 표시한 최적 칸이 다를 수 있다.

## 원본과 맞춘 세부 규칙

| 항목 | 적용 방식 |
|---|---|
| 이진 필터 | Hamming 저역통과 FIR 차수 16, 정규화 차단 주파수 0.4를 복소 변조 |
| 이진 고역 필터 | 원본의 역순·부호·모듈로 인덱싱을 그대로 적용; `h`는 17탭, `g`는 16탭 |
| 삼진 필터 | 차수 24, 정규화 차단 주파수 `(2/3) × 0.4`, 세 중심 주파수로 복소 변조 |
| 필터 적용 | MATLAB `filter`에 대응하는 SciPy `lfilter`; 인과 FIR 필터링 |
| 이진 다운샘플링 | 원본의 `2:2:N`, Python의 `[1::2]` |
| 고역 가지 정렬 | 원본의 `d .* (-1).^(1:N)` |
| 삼진 다운샘플링 | 원본의 `3:3:N`, Python의 `[2::3]` |
| 이진 SK 과도응답 제외 | 다운샘플링 결과에서 저역 16개, 고역 15개 샘플 제외 |
| 삼진 SK 과도응답 제외 | `K_wpQ_local`과 같이 16개 샘플 제외; 삼진 필터 길이 25를 사용하지 않음 |
| 신호 길이 조건 | 원본의 `nlevel ≤ log2(N) - 7`; 5레벨은 최소 4096샘플 필요 |
| 동률 선택 | 낮은 주파수의 칸을 먼저, 같은 위치에서는 위쪽 행을 먼저 선택 |

각 대역 신호를 `z`라 하고 평균을 제거하면 SK는 다음과 같다.

\[
K = \frac{E[|z|^4]}{E[|z|^2]^2} - c
\]

실수 원신호인 레벨 0에서는 `c = 3`, 복소 필터 출력에서는 `c = 2`다.
에너지가 원본의 `eps`보다 작으면 0을 반환한다.
별도의 유한 표본 보정이나 추가 Hilbert 변환은 적용하지 않는다.

## 기존 프로젝트와의 연결

기존 공개 함수 이름과 인자를 유지한다.

```python
result = compute_kurtogram(signal, fs)
band = select_best_band(signal, fs)
```

`result`는 기존처럼 `fs`, `rows`, `best`를 포함하고,
`band`는 기존처럼 `(low_hz, high_hz)`를 반환한다.
삼진 레벨 때문에 `level`은 실수가 된다.
`main.py`의 레벨 출력과 `plotting.py`의 행 배치를 이에 맞췄다.
행 배치는 실제 레벨 값 대신 행 인덱스를 사용해 빈틈과 겹침을 없앤다.

이번 이식 대상은 **Fast Kurtogram의 대역 탐색 계산**이다.
선택한 대역의 후속 처리는 기존 `envelope.py`의 Butterworth → Hilbert →
일반 포락선 → FFT 경로를 사용하며 진폭 단위는 g다.
Antoni 원본의 선택적 대화형 `Find_wav_kurt`와 제곱 포락선 표시를
전체 프로젝트에 적용한 것은 아니다.
최소 폭 600 Hz 제한도 요청에 따른 프로젝트 정책이며, 원본의 무제한 최댓값 선택과 구분한다.

## 검증과 재실행

Antoni 원본에서 그래프와 대화형 입력만 제거한 MATLAB 함수로 기준 결과를 생성한다.
MATLAB에 Signal Processing Toolbox가 설치되어 있지 않아 `fir1`은
이상 저역통과 응답 × 대칭 Hamming 창 × DC 이득 정규화로 별도 계산했다.
따라서 MATLAB 내장 `fir1`을 포함한 전체 함수의 직접 실행 대조는 아니다.
그 외 `K_wpQ`, `K_wpQ_local`, `DBFB`, `TBFB`, `kurt` 계산은 원본을 사용한다.

합성 입력 5개와 실제 CWRU 입력 40개에 대해 전체 SK 행을 비교한다.
합성 입력에는 백색 잡음, 반복 충격, 홀수 길이 신호, 1·2레벨 계산을 포함한다.
이 기준값 일부는 `tests/data/antoni_reference.npz`에 보관한다.

```powershell
python -B -m unittest discover -s tests -v
python -B main.py
```

첫 명령은 기준값 대조와 최소 폭 정책을 검사한다.
두 번째 명령은 전체 그래프와 기존 분류·평가 결과를 다시 생성한다.
검증 상세는 [기준값 설명](../tests/data/README.md)에 기록한다.

## 이번 실행 결과

- 8개 회귀 검사와 `main.py`의 Phase 1–5 실행이 통과했다.
- 합성 5개 + 실제 CWRU 40개의 전체 SK 행에서 최대 차이는 약 `2.5e-12`였다.
- Kurtogram 40장, 포락선 스펙트럼 40장, 비교 그래프 34장을 다시 생성했다.
- `IR007_0`은 9레벨까지 계산해도 전체 SK 최댓값이 `2.395863773038575`이고,
  최적 레벨은 0, 중심 주파수는 3000 Hz, 폭은 6000 Hz였다.
  첨부 논문의 Fig. 9에 제시된 `2.3959`, 레벨 0, 중심 3 kHz, 폭 6 kHz와 일치한다.
  프로젝트의 기본 최대 레벨은 기존 설정인 5를 유지한다.

기존 분류기 설정으로 다시 실행한 통합 결과는 다음과 같다.

| 실험 | 이전 Accuracy | 적용 후 Accuracy | 이전 Macro F1 | 적용 후 Macro F1 |
|---|---:|---:|---:|---:|
| 볼 포함 4종 | 0.5797 | 0.5671 | 0.5177 | 0.5106 |
| 볼 제외 3종 | 0.8327 | 0.8145 | 0.7926 | 0.7768 |

원본 알고리즘의 계산 재현과 기존 고정 임계값 분류기의 성능은 각각 평가한다.
이번 실행에서는 최적 대역이 달라지며 성능이 소폭 낮아졌다.
볼 결함의 F1은 두 실행 모두 0이다. 임계값이나 분류 규칙은 이번 변경에서 재조정하지 않았다.
